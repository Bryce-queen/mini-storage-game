# 收纳上头了 - 微信小游戏 MVP

一个原生 Canvas 微信小游戏原型：拖拽口红、香水、面霜、粉饼到化妆台收纳格，同类 3 个自动合成升级，完成顾客订单获得分数。主打“一格都不能乱”的治愈收纳爽感。

## 玩法

- 启动页展示核心卖点，可以直接开始或分享给好友。
- 支持无尽模式、关卡模式和每日挑战。
- 首次开局会显示 3 步新手引导。
- 启动页可进入设置，开关音效、背景音乐、震动或重看新手引导。
- 下方化妆包每次给 3 个随机物品。
- 拖拽物品到上方 4x4 收纳格。
- 同类同等级满 3 个会自动合成成更高级物品。
- 达成顶部订单目标会获得分数，并刷新新订单。
- 订单支持单品和 2-3 件组合妆包，后期关卡需要规划保留多个材料。
- 拖拽时会提示放下后是否触发合成，订单相关物品会高亮。
- 拖放判定做了宽容区域，落点会显示半透明幽灵预览，格子快满时会预警。
- 同类相邻和一整行同类会获得“整齐摆放”奖励。
- 合成产物会保留在玩家刚放下的位置，增强空间规划。
- 可以撤回上一步，刷新物品会扣 20 分。
- 每局可复活一次，清理 4 个低级物品继续玩。
- 格子填满且无法放入时游戏结束。
- 结算页展示本局分数、评价、复活/再来和分享战绩。
- 结算页展示击败百分比，合成会出现 Combo 和爽感浮字。

## 模式

- 无尽模式：不限制订单和步数，目标是冲最高分。
- 关卡模式：扩展到 20 关，每 5 关逐步加入指定类型订单、限步和杂物格。
- 每日挑战：按当天日期生成固定随机种子，所有玩家同一题，并带同局挑战分享文案。
- 杂物格：部分关卡会出现不可放置的杂物格，复活可优先清理杂物。
- 多样关卡目标：支持完成订单、清理杂物、合成指定数量 Lv.3、做出整行同类。
- 星级评价：结算按通关、步数、刷新次数和是否复活给 1-3 星。

## 广告占位

- `game.js` 顶部 `AD_CONFIG.rewardedVideoAdUnitId` 可配置激励视频广告位。
- `game.js` 顶部 `AD_CONFIG.interstitialAdUnitId` 可配置插屏广告位。
- 当前未填广告位时，会显示占位提示并直接发放奖励，方便开发测试。
- 当前刷新按钮需要至少 20 分并扣 20 分，避免 0 分无限刷新；后续可另加“看广告免费刷新”按钮。

## 视听反馈

- 物品图标使用 Canvas 原创扁平绘制，不依赖外部图片素材。
- 画面采用奶油粉渐变、化妆镜装饰、卡片阴影、高光按钮和轻拟物物品图标。
- 窗口尺寸优先使用 `wx.getWindowInfo()`，旧基础库自动回退到 `wx.getSystemInfoSync()`。
- 放置、合成、订单完成、按钮、失败均有本地 wav 音效，并内置原创循环背景音乐。
- 合成、订单完成、复活、通关会触发克制的微信震动反馈。
- 合成和订单完成会触发缩放高亮与粒子爆开动画。
- 合成连击会触发 `Combo` 浮字，订单完成会展示网感短句。
- 粒子特效包含星光、爱心和圆点，强化短视频观感。
- 订单生成采用半随机逻辑，会优先参考场上和待收纳物品，减少纯随机挫败。
- 内置原创分享卡片：`assets/share-card.png`。
- 结算时会尝试生成带分数、完成订单、击败百分比的动态分享图，失败时回退静态分享卡。

## 运行

1. 打开微信开发者工具。
2. 选择“小游戏”。
3. 导入本目录：`mini-storage-game`。
4. AppID 可先选择测试号或游客模式。
